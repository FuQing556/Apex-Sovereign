# Apex Sovereign

《基于 Unity 的 3D 赛车游戏设计与实现》毕业设计原型。可以在车库选择赛车和赛道，参加计时赛，或进入训练场练习。山脊计时赛共两圈，内置玩家实跑的「初见」和「初见2」两条幽灵车轨迹。

[观看山脊赛道实机演示（哔哩哔哩）](https://www.bilibili.com/video/BV1VEyHz1EXb/)

## 运行工程

1. 克隆仓库，在 Unity Hub 中添加仓库根目录，使用 **Unity 6000.6.0f1** 打开。首次打开需要联网还原 Packages 依赖，其中 Unity MCP 通过 Git 下载。
2. 打开 `Assets/_Project/Scenes/Bootstrap.unity`，点击播放进入车库。
3. 选择「柴田 31 号 · GR86」和山脊赛道，开始计时赛。简单驾驶模式下，W 给油，A / D 转向，S 制动，接近停车后继续按 S 可倒车，空格拉后轮手刹。

- [游戏源码与资源](Assets/_Project) 包含车库、车辆动力学、赛道、计时、幽灵车和驾驶界面。
- [31 号车装配源文件](毕设资料/02-车辆设计/SHIBATA-31/精细装配) 包含 Blender 模型、建模脚本、装配数据及分部件渲染图。[山脊美术目录](毕设资料/04-赛道设计/山脊美术) 包含场景生成脚本和材质数据。
- [开发工具](Tools) 包含驾驶音效生成及遥测分析脚本。历史分析脚本使用对应试验产生的本地日志。
- [漂移与轮胎动力学参考文献](毕设资料/01-前期调研/漂移与轮胎动力学.bib) 提供作者、出处和原文入口。
