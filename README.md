# Apex Sovereign

《基于 Unity 的 3D 赛车游戏设计与实现》毕业设计原型。车库可选后驱的柴田 31 号 GR86 和前驱的马青骅 155 号领克 03 FL TCR。山脊大奖赛道和滨海湾夜赛均可选计时赛或四车竞速。山脊跑两圈，滨海湾跑一圈。山脊内置玩家实跑的「初见」和「初见2」两条幽灵车轨迹。

[观看山脊赛道实机演示（哔哩哔哩）](https://www.bilibili.com/video/BV1VEyHz1EXb/)

## 运行工程

1. 克隆仓库，在 Unity Hub 中添加仓库根目录，使用 **Unity 6000.6.0f1** 打开。首次打开需要联网还原 Packages 依赖，其中 Unity MCP 通过 Git 下载。
2. 打开 `Assets/_Project/Scenes/Bootstrap.unity`，点击播放进入车库。
3. 车库默认展示「柴田 31 号 · GR86」。用「切换场地」选赛道，点「模式」切换计时赛和四车竞速，再点出发。简单驾驶模式下，W 给油，A / D 转向，S 制动，接近停车后继续按 S 可倒车，空格拉后轮手刹。
4. 四车竞速可切换「车辆规则」。纯净场四辆都用你选的车型。全随机场四辆各自抽车型，允许重复。两种规则下，玩家始终使用实际出赛车型在车库保存的差速器和后轮盘面，三个对手每次发车各自抽配件。车库里可切换车型，分别装配。
